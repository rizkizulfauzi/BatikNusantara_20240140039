Data service untuk developer

Ragam batik, siap dipakai lewat API.

Layanan data motif batik yang menyediakan informasi daerah asal, kategori motif, filosofi, teknik pembuatan, bahan kain, tingkat kerumitan, dan atribut lainnya. Akses data menggunakan API key setelah pengguna login.

Mulai sekarang Lihat endpoint

Dibuat seperti layanan API sungguhan

User mengelola kredensial, sementara aplikasi client memakai API key untuk mengambil data.

01

JWT Login

Register dan login akun menggunakan JSON Web Token untuk fitur dashboard.

02

API Key

Setiap user dapat membuat API key yang dipakai aplikasi lain untuk mengakses dataset.

03

65 Data

Dataset awal berisi 65 motif dengan atribut kompleks dan query filter, sort, serta pagination.
