Authentication

POST /api/register
{
  "nama": "Rizki",
  "email": "rizki@mail.com",
  "password": "12345678"
}
POST /api/login
{
  "email": "rizki@mail.com",
  "password": "12345678"
}

Gunakan token dari response login sebagai Authorization: Bearer TOKEN.

API Key

GET /api/batik/:id
GET /api/batik/1
x-api-key: rb_live_xxxxxxxxx
